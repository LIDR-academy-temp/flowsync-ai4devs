# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

FlowSync: team task management practice project. Two independent npm projects, no root package.json:

- `backend/` — AdonisJS 7 API (TypeScript, ESM, SQLite via better-sqlite3, Lucid ORM, VineJS validation). Port 3333.
- `frontend/` — React 19 + Vite 8 + TypeScript. Port 5173.

Run commands from inside each folder.

## Commands

Backend (`cd backend`):

```bash
npm install && cp .env.example .env && node ace generate:key && node ace migration:run   # first-time setup
npm run dev          # node ace serve --hmr
npm run lint         # eslint .
npm run typecheck    # tsc --noEmit
npm test             # node ace test (Japa)
node ace test --files tests/functional/foo.spec.ts   # single test file
node ace test functional                              # one suite (unit | functional)
```

Frontend (`cd frontend`):

```bash
npm run dev
npm run lint         # oxlint (not eslint)
npm run build        # tsc -b && vite build
```

No frontend test runner. No tests exist yet in backend (only `tests/bootstrap.ts`; suites expect `tests/unit/**` and `tests/functional/**` `*.spec.ts`).

## Backend architecture

- API mounted under `/api/v1` in `start/routes.ts`: `auth/signup`, `auth/login` (public); `account/profile`, `account/logout` (behind `middleware.auth()`).
- Controllers are referenced via generated `controllers` from `#generated/controllers` (`.adonisjs/server/`), not direct imports. `.adonisjs/` is committed and generated by Adonis tooling — don't hand-edit.
- Auth: default guard `api` = opaque access tokens (`User.accessTokens`); `web` session guard also configured. Signup/login return `{ user, token }` via `serialize()` and `UserTransformer` (`app/transformers`), not raw models.
- Validation in `app/validators/*` (VineJS). Signup payload: `fullName` (nullable), `email` (unique), `password` (8–32), `passwordConfirmation`. Validation errors return 422 with per-field messages.
- Imports use package.json `imports` aliases (`#models/*`, `#validators/*`, `#start/*`, …) — keep `.js`-resolved aliases, not relative paths.
- Dev CORS allows any origin (`config/cors.ts`); production allows none.
- DB schema classes are generated into `database/schema.ts` from migrations.

## Frontend architecture

Small Vite template app: `App.tsx` renders `SignupForm` which POSTs to the backend signup endpoint (base URL hardcoded fallback `http://localhost:3333`). tsconfig has `verbatimModuleSyntax` (use `import type`) and `allowImportingTsExtensions` (imports written with `.tsx` extension, e.g. `./SignupForm.tsx`).
